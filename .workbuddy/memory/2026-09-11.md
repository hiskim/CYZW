# 2026-09-11

## macOS 账号分组管理（树形侧边栏）重构

需求：为 macOS SwiftUI + WKWebView 游戏多开管理器加入账号分组管理，左侧侧边栏由扁平列表改为 DisclosureGroup 树形分组。

### 改动文件（均在 ios/Shell/）
- `ShellModels.swift`：`AccountGroup` 升级为树形节点（id/groupName/colorName/isHidden/sortOrder/isExpanded/accounts）；自定义 Codable —— accounts 不持久化、旧数据 `name` 键自动迁移为 `groupName`、isExpanded 缺省 true；新增 `ungroupedID` 伪分组与 `isSynthetic`；新增 `typealias AccountModel = Account`。
- `AccountLibraryViewModel.swift`：数据源改为 `groups: [AccountGroup]` 树（["全部","未分组"] 伪分组 + 自定义分组，伪分组固定置顶）；`syncTree()`（resortTree + materializeMembers）统一物化组内账号；`setExpanded(_:forGroupID:)` 持久化展开状态（伪分组走独立 UserDefaults 键）；`importFiles(from:targetGroupID:)` 支持"添加账号到指定分组"（未分组=不指派）。
- `MacMultiOpenManagerView.swift`：侧边栏 `groupedAccountList`（ScrollView + LazyVStack + DisclosureGroup）；分组表头 = 色点 + 组名 + `[运行中/总数]` + ➕/▶️/⏹️（一键启停分组，startGroup 依赖 WorkspaceViewModel.start 的已运行去重）；内容区复用 AccountManagerRow；右侧矩阵数据源改为 `allRunningAccounts`（flatMap 展平分组中运行中账号，单元格仍解析 WorkspaceItem 保留实例控制）；搜索时组内过滤 + 强制展开 + 隐藏无匹配组；移除旧的分组 chips 与 selectedGroupID。
- `AccountLibraryView.swift`：`name`→`groupName` 引用修复 + updateGroup 参数标签更新。

### 关键决策与坑
- **@Observable 未采用**：项目 MACOSX_DEPLOYMENT_TARGET = 12.0，@Observable 需 macOS 14+；沿用全项目统一的 ObservableObject/@Published。若将来升到 14 可机械迁移。
- **坑 1**：同一文件并行发多个 Edit 会竞态覆盖（AccountLibraryView 的 519 行修改被后续并行 Edit 回滚），同文件编辑必须串行。
- **坑 2**：整文件重写时漏掉了 secondarySection/workspace 两个成员，报"cannot find in scope"而非语法错误（花括号仍平衡），需靠成员清单逐项核对。
- **grep 教训**：`group?.name` 不会被 `group\.name` 正则匹配到，检查旧引用时用 `\.name\b` 更稳。
- 验证方式：`xcodebuild -project IOS2-Mac.xcodeproj -scheme IOS2-Mac -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO build` → BUILD SUCCEEDED。grep 过滤 xcodebuild 输出时避免用裸 "BUILD"（会匹配大量 export 变量行），用 `BUILD (SUCCEEDED|FAILED)`。
- 持久化兼容：旧 UserDefaults 数据（groupDefinitionsKey 无 isExpanded、name 键）解码自动迁移，不丢分组。

## 分组管理弹窗去重（第二轮）

用户反馈：「分组管理」sheet 底部「新建分组」再弹一层 GroupEditorSheet（内含「创建分组」按钮），交互重复；且 macOS 上 sheet 套 sheet 导致 680×500 编辑器被压成细条（渲染 bug）。

方案：macOS 端去掉第二层弹窗，改内联编辑——
- 新增 `GroupEditorMode`（.create / .edit(AccountGroup)，Equatable）与 `GroupInlineEditor`（名称自动聚焦 + 颜色 swatches + 可折叠账号多选 + 重名校验 + 回车提交）。
- 点「新建分组」→ "我的分组" Section 顶部插入内联表单卡片；点行内铅笔「编辑」→ 原行原地替换为表单。
- iOS 端保持原 GroupEditorSheet 体验（GroupManagementView 的 sheet 修饰符保留，macOS 不再触发）。
- 抽取共享组件 `groupAccountSelectionRow`（文件级私有函数）供新旧两套编辑器复用。
- macOS sheet 尺寸 500×360 → 560×470；`.toggleStyle(.checkbox)` 需 `#if os(macOS)` 保护（iOS 无此样式）。
- xcodebuild 验证 BUILD SUCCEEDED。

## 修复：分组管理底部工具栏被裁剪（第三轮）

用户截图：分组管理 sheet 里「新建分组/完成」工具栏消失。
根因：MacMultiOpenManagerView 弹 sheet 时外层残留 `.frame(width: 500, height: 360)`，与 macBody 内部新尺寸 560×470 双层叠加，上下各裁 ~55px（顶部标题裁剩细条、底部工具栏整体不可见）。
修复：移除弹出点外层 frame，尺寸统一由 macBody 内部定义并加注释说明。教训：**弹窗尺寸只在一个地方定义**——改内部尺寸时必须全局检查所有弹出点的包裹 frame。
- iOS 端 AccountLibraryView 用 NavigationLink 推入，无 frame 包裹，不受影响。
- xcodebuild 验证 BUILD SUCCEEDED。
